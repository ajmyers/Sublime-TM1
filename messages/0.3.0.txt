TM1 Planning Analytics Developer Tools 0.3.0
============================================

0.3.0 is a rewrite of the package, on skipcheck-tm1, a TM1 REST API client
that Package Control installs with it. It needs Sublime Text 4 build 4213
or later; earlier builds stay on 0.2.x.

Your projects keep working
--------------------------

Their settings, .pro and .rux files, commands and keybindings carry over.

The one change you'll notice: the password stored in the project file
(obfuscated, not encrypted) is no longer used. It's asked for once per
Sublime session and kept only in memory. To remove the stored one from the
project, run 'TM1: Config - Update Current TM1 Project'. A teammate still on
0.2.x needs it there, so it stays until you choose.

What's new
----------

- Signing in, however your TM1 is secured: TM1's own security, CAM with a
  user and password, or single sign-on in a browser window (a Chromium-based
  browser). It's worked out from the server.
- 'TM1: Config - Create New TM1 Project' asks only for the server's host or
  URL, and finds the port, HTTPS and the login itself.
- New: 'TM1: Config - Sign Out' forgets the password and the sign-in.
- Put shows TM1's errors on their own lines in the file, with the message
  beside each one, instead of a popup.
- Run lists the processes without freezing the editor, asks for each
  parameter, then shows the run's own log lines and error files in a panel.
- New: 'TM1: Console - Tail Server Log' follows the server's message log.
- The console and Kill Thread no longer block the editor while they refresh.
- Format Process changes only the code of the four procedures.
- Completions from 'TM1: Get' are no longer written into the project file;
  the ones 0.2.x wrote there are removed on the next Get.

If a command says libraries are missing, run
'Package Control: Satisfy Libraries'.

More: https://github.com/ajmyers/Sublime-TM1#upgrading-from-02x
